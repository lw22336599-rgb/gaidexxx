# 批量续费功能说明

## 功能概述

实现了店铺批量续费功能，允许用户选择多个店铺进行批量续费操作。

## 功能特性

### 1. 批量续费按钮动态变化

- **未选择店铺时**：显示"批量续费"按钮（主色调）
- **点击后进入批量续费模式**：显示"取消批量续费"按钮（警告色）
- **选择店铺后**：
  - 显示功能选择下拉框（选择要续费的功能）
  - 显示"确认续费"按钮

### 2. 功能选择下拉框

- 通过调用 `GetShopListFunctionColumns` API 获取当前平台支持的功能列表
- 下拉框仅在选择了店铺后显示
- 自动选中第一个功能作为默认值

### 3. 批量续费对话框

点击"确认续费"后弹出对话框，包含以下内容：

#### 左侧：续费店铺列表
- 显示所有选中的店铺信息
- 包含店铺名称、门店ID、城市等信息
- 显示总共选择的店铺数量

#### 右侧：续费套餐选择
- 通过调用 `GetFunctionPrices` API 获取价格列表
- 根据选择的功能代码搜索可用套餐
- 以单选形式展示所有可用套餐
- 每个套餐显示：
  - 套餐名称
  - 价格（积分/家）
  - 续费天数
  - 包含的功能列表

#### 底部：总费用计算
- 实时计算总费用 = 选中店铺数量 × 套餐价格
- 清晰显示计算公式和结果

### 4. 续费确认

- 点击"确认续费"按钮
- 调用 `BatchPayForShopFunc` API 执行批量续费
- 显示续费结果：
  - 成功续费的店铺数量
  - 总花费积分
  - 续费天数
- 续费成功后：
  - 自动退出批量续费模式
  - 清空选中的店铺
  - 刷新店铺列表

## 涉及的 API

1. **GetShopListFunctionColumns**
   - 路径：`/FunctionApp/GetShopListFunctionColumns`
   - 参数：`shopType` (平台类型)
   - 返回：功能列表（包含功能代码和名称）

2. **GetFunctionPrices**
   - 路径：`/FunctionPrice/GetFunctionPrices`
   - 参数：
     - `shopType`：平台类型（如：1）
     - `priceTitle`：功能名称（如："自动出餐"）
     - `isKeyWord`：是否为关键词模式（必须传 `true`）
   - 返回：价格套餐列表
   - 示例：
     ```typescript
     await apiManager.functionpriceApi.GetFunctionPrices(
       1,              // shopType
       "自动出餐",     // priceTitle (功能名称)
       true            // isKeyWord (关键词模式)
     )
     ```

3. **BatchPayForShopFunc**
   - 路径：`/FunctionPrice/BatchPayForShopFunc`
   - 参数：
     - `shops`：店铺 ID 数组（最多100个）
     - `func_price`：功能价格 ID
   - 返回：批量续费结果

## 使用流程

1. 进入店铺列表页面（美团、饿了么等）
2. 点击"批量续费"按钮进入批量续费模式
3. 在表格中勾选需要续费的店铺
4. 在下拉框中选择要续费的功能
5. 点击"确认续费"按钮
6. 在弹出的对话框中选择续费套餐
7. 查看总费用，确认无误后点击"确认续费"
8. 等待续费完成，查看续费结果

## 注意事项

- 批量续费最多支持100家店铺
- 确保账户有足够的积分余额
- 续费失败时会显示详细的错误信息
- 续费成功后会自动刷新店铺列表，显示最新的到期时间

## 调试说明

### 问题：功能列表下拉框显示"无数据"

如果功能列表下拉框没有显示数据，请按以下步骤排查：

1. **打开浏览器开发者工具（F12）**
   - 切换到 Console 标签页
   
2. **点击"批量续费"按钮进入批量续费模式**
   - 查看控制台输出，应该看到：
     ```
     开始获取功能列表，平台类型: 1
     功能列表返回结果: [...]
     处理后的功能选项: [...]
     ```
   
3. **检查返回的数据**
   - 如果看到"功能列表为空"警告，说明后端没有返回数据
   - 如果看到错误信息，说明 API 调用失败
   
4. **切换到 Network 标签页**
   - 查找 `GetShopListFunctionColumns` 请求
   - 检查请求状态码和响应内容
   - 确认请求 URL 和参数是否正确

5. **常见问题**
   - 如果返回 401/402：需要重新登录
   - 如果返回 404：检查 API 路径是否正确
   - 如果返回 500：后端服务异常，联系后端开发人员
   - 如果返回空数组：该平台类型可能还没有配置功能项

### 问题：价格列表显示"暂无可用套餐"

如果价格列表没有数据：

1. **检查控制台日志**
   - 应该看到：
     ```
     开始获取价格列表: {shopType: 1, functionCode: "ZDCC"}
     价格列表返回结果: [...]
     ```
   
2. **确认功能代码是否正确**
   - 功能代码应该来自功能列表下拉框
   - 常见功能代码：ZDCC（防漏单）、IMZDHF（自动回复）、ZDHP（自动回评）等
   
3. **检查后端数据**
   - 确认该平台类型下该功能是否已配置价格套餐
   - 确认价格套餐是否已启用
