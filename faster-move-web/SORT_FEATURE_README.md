# 店铺列表排序功能实现说明

## 实现概述

已成功为门店管理V2下的基础版和运营版实现了店铺列表排序功能。**排序方式：直接点击表格列头进行排序。**

## 修改的文件

### 1. 类型定义

#### `src/TsModel/Alien/Controllers/Shop/OrderDirection.ts`
- ✅ 已存在,定义排序方向枚举
- `Asc = 0` - 升序
- `Desc = 1` - 降序

#### `src/TsModel/Alien/Controllers/Shop/Get_ShopList_parm.ts`
- ✅ 添加排序参数字段:
  - `order_by?: string | null` - 排序字段名称
  - `order_direction?: OrderDirection | null` - 排序方向

### 2. 基础版 - MtFeatureV2.vue

#### 新增功能:
1. **表格列头排序**
   - 在表格列头直接点击排序(支持2个基础字段)
     - 实时收入 (income)
     - 实时订单 (order_num)
   - 点击列头切换排序方向: 默认 → 降序 → 升序 → 默认
   - 支持自定义后端排序 (sortable="custom")

2. **状态管理**
   - 在 `queryParams` 中添加 `order_by` 和 `order_direction` 字段
   - 在 `ShopTypeState` 接口中添加排序状态
   - 排序状态会按店铺类型独立保存和恢复

3. **交互逻辑**
   - 点击列头时自动刷新列表
   - 排序时重置页码为第1页
   - 切换店铺类型时保持该类型的排序设置
   - 再次点击同一列头会切换排序方向

### 3. 运营版 - MtFeatureV2Operation.vue

#### 新增功能:
1. **表格列头排序**
   - 在表格列头直接点击排序(支持6个运营数据字段)
     - 实时收入 (income)
     - 有效订单 (order_num)
     - 曝光人数 (show_num)
     - 入店转化率 (in_ratio)
     - 下单转化率 (order_ratio)
     - 单均到手 (avg_income)
   - 点击列头切换排序方向: 默认 → 降序 → 升序 → 默认
   - 支持自定义后端排序 (sortable="custom")

2. **状态管理**
   - 与基础版相同的状态管理逻辑
   - 运营版默认筛选 APPDATA 功能且状态为已开启

3. **交互逻辑**
   - 点击列头时自动刷新列表
   - 排序时重置页码为第1页
   - 切换店铺类型时保持该类型的排序设置
   - 再次点击同一列头会切换排序方向

## 技术实现细节

### 表格排序实现
- **Element Plus 自定义排序**: 使用 `sortable="custom"` 启用后端排序
- **排序事件监听**: 监听 `@sort-change` 事件获取排序信息
- **事件传递**: ShopTable/ShopTableOperate组件将排序事件传递给父组件
- **排序状态映射**: 
  - Element Plus: `ascending` → 后端: `Asc` (0)
  - Element Plus: `descending` → 后端: `Desc` (1)
  - Element Plus: `null` → 后端: 清空排序

### API 调用
- **基础版**: 通过 `getShopFdmv(queryParams)` 调用 `/shopmg/getshoplist` 接口
- **运营版**: 通过 `apiManager.shopmgApi.GetShopListV2(queryParams)` 调用 `/shopmg/getshoplistv2` 接口
- 排序参数自动包含在请求参数中传递给后端

### 状态持久化
- 每个店铺类型的排序设置独立保存
- 切换店铺类型时自动恢复该类型的排序设置
- 使用 `ShopTypeState` 接口管理状态

### 用户体验优化
- 排序时显示平滑过渡,保持旧数据可见避免闪烁
- 排序后自动跳转到第1页
- 点击列头直观易用,符合用户习惯
- 排序图标清晰显示当前排序状态

## 使用说明

### 基础版
1. 进入门店管理V2 - 基础版
2. 找到表格中的"实时收入"或"实时订单"列头
3. 点击列头文字旁边的排序图标
4. 第一次点击:降序排序
5. 第二次点击:升序排序
6. 第三次点击:取消排序(恢复默认排序)

### 运营版
1. 进入门店管理V2 - 运营版
2. 找到表格中可排序的列头(实时收入、有效订单、曝光人数、入店转化率、下单转化率、单均到手)
3. 点击列头文字旁边的排序图标
4. 第一次点击:降序排序
5. 第二次点击:升序排序
6. 第三次点击:取消排序(恢复默认排序)

## 默认行为
- 不选择排序字段时,使用默认排序(按更新时间降序)
- 默认排序方向为降序
- 清空排序字段后恢复默认排序

## 注意事项
1. 字段名严格区分大小写,与后端保持一致
2. 只能对文档中列出的白名单字段进行排序
3. 空值在降序时排在最后,升序时排在最前
4. 排序状态按店铺类型独立保存
