当调用此命令时，先累加一次 package.json 中的版本号，然后获取用户最近一星期提交和未提交的更新变动更新项目目录中的 release-notes-web.txt 中的内容,如果更改的是electron的主进程代码，请更新  release-notes.txt ，从以下几个角度更新
【新功能】
新功能同有时间限制，但最多显示5个新功能，最新功能要按排在前面
【修复】
最近一星期的修复说明（需清除超过一星期的修复说明） 最新修复的要排前面
【优化】
最近一星期的优化说明（需清除超过一星期的优化说明） 最新优化的要排前面

注意：
1. 更新说明是面向普通用户，普通用户不懂任何技术，所以更新说明要通俗易懂！
2. 排版简约清爽，适当的emoji表情
