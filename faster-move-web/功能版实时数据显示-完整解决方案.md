# 功能版实时收入和订单数据显示 - 完整解决方案

## 问题描述

功能版店铺列表的"实时收入/订单"列显示为 0元/0单，但接口实际返回了数据。

## 问题根本原因

### 数据结构不匹配

**接口返回的数据结构：**
```json
{
  "income": 237.78,      // ✅ 实时收入在 row 对象上
  "order_num": 21,       // ✅ 有效订单在 row 对象上
  "func_info": [...],
  // ❌ 没有 extra_data 字段
}
```

**前端组件使用的数据：**
```vue
<!-- 原代码（错误） -->
{{ formatIncome(row.extra_data?.income) }}  // ← extra_data 不存在，返回 undefined
{{ formatOrderNum(row.extra_data?.order_num) }}  // ← 导致显示 0元/0单
```

## 解决方案

### 修改1：数据兼容性处理

**文件：** `src/views/shop/componentsV2/ShopTable.vue`
**位置：** 第473行和第479行

**修改内容：**
```vue
<!-- 修改前 -->
{{ formatIncome(row.extra_data?.income) }}
{{ formatOrderNum(row.extra_data?.order_num) }}

<!-- 修改后 -->
{{ formatIncome(row.extra_data?.income ?? row.income) }}
{{ formatOrderNum(row.extra_data?.order_num ?? row.order_num) }}
```

**逻辑说明：**
- 使用空值合并运算符 `??`
- 优先使用 `row.extra_data?.income`（运营版）
- 如果不存在，使用 `row.income`（功能版）✅
- 同时兼容两种数据结构

### 修改2：样式优化

**文件：** `src/views/shop/componentsV2/ShopTable.vue`
**位置：** 第3789-3817行（CSS样式）

**优化内容：**
