# 修复零售类店铺无法打开后台的问题

## 🐛 问题描述

用户反馈以下店铺类型点击"打开店铺"按钮无法进入后台：
- ❌ 美团闪购（shop_type = 3）
- ❌ 美团医药（shop_type = 4）
- ❌ 饿百零售（shop_type = 5）

## 🔍 问题分析

### 根本原因
这些平台的 cookies 需要设置到**多个子域名**，原来的代码只设置到了单个域名，导致登录状态无法正确识别。

### 对比工作正常的平台
- ✅ **京东到家**：设置了 19 个子域名
- ✅ **美团外卖**：虽然只设置了一个，但美团外卖的域名结构相对简单

### 问题平台的特点
1. **美团闪购和美团医药**：属于美团系，共享部分域名
2. **饿百零售**：属于饿了么系，需要多个饿了么相关域名

## ✅ 修复方案

### 1. 美团闪购（shop_type = 3）

**修复前**：
```typescript
// 只设置到闪购主域名
await electron.setCookies(
  `persist:webview_${row.id}`,
  row.cookies,
  'https://shangoue.meituan.com'
)
```

**修复后**：
```typescript
// 设置到多个美团相关域名
await electron.setCookies(`persist:webview_${row.id}`, row.cookies, 'https://shangoue.meituan.com')
await electron.setCookies(`persist:webview_${row.id}`, row.cookies, 'https://e.waimai.meituan.com')
await electron.setCookies(`persist:webview_${row.id}`, row.cookies, 'https://waimai.meituan.com')
await electron.setCookies(`persist:webview_${row.id}`, row.cookies, 'https://meituan.com')
```

### 2. 美团医药（shop_type = 4）

**修复前**：
```typescript
// 只设置到医药主域名
await electron.setCookies(
  `persist:webview_${row.id}`,
  row.cookies,
  'https://yiyao.meituan.com/main/frame'
)
```

**修复后**：
```typescript
// 设置到多个美团相关域名（去除路径，只保留域名）
await electron.setCookies(`persist:webview_${row.id}`, row.cookies, 'https://yiyao.meituan.com')
await electron.setCookies(`persist:webview_${row.id}`, row.cookies, 'https://e.waimai.meituan.com')
await electron.setCookies(`persist:webview_${row.id}`, row.cookies, 'https://waimai.meituan.com')
await electron.setCookies(`persist:webview_${row.id}`, row.cookies, 'https://meituan.com')
```

### 3. 饿百零售（shop_type = 5）

**修复前**：
```typescript
// 只设置到 nr.ele.me
await electron.setCookies2(
  `persist:webview_${row.id}`,
  JSON.stringify(out),
  'https://nr.ele.me'
)
```

**修复后**：
```typescript
// 设置到多个饿了么相关域名
await electron.setCookies2(`persist:webview_${row.id}`, JSON.stringify(out), 'https://nr.ele.me')
await electron.setCookies2(`persist:webview_${row.id}`, JSON.stringify(out), 'https://ele.me')
await electron.setCookies2(`persist:webview_${row.id}`, JSON.stringify(out), 'https://shop.ele.me')
```

## 📊 技术细节

### Cookie 域名设置原理

当设置 cookie 到某个域名时，浏览器会：
1. 检查当前页面的域名
2. 验证 cookie 的域名是否匹配
3. 只有匹配时才会发送 cookie

### 为什么需要多个域名

这些平台的特点：
```
美团闪购访问流程：
shangoue.meituan.com → 跳转到 → e.waimai.meituan.com → 需要登录信息
                                                          ↑
                                          如果没有在这里设置 cookie，就无法登录
```

```
美团医药访问流程：
yiyao.meituan.com → 加载资源 → waimai.meituan.com → 需要登录信息
                                                      ↑
                                       如果没有在这里设置 cookie，就无法登录
```

```
饿百零售访问流程：
nr.ele.me → 调用 API → shop.ele.me → 需要登录信息
                                      ↑
                       如果没有在这里设置 cookie，就无法登录
```

## 🔍 调试方法

### 检查 Cookie 是否设置成功
在 Electron DevTools 中：
```javascript
// 打开控制台
document.cookie

// 应该看到相关的 cookie
// 如: token=xxx; _csrf=yyy; ...
```

### 检查网络请求
在 Network 面板中：
1. 找到后台 API 请求
2. 查看 Request Headers
3. 确认 Cookie 是否包含在请求中

### 常见问题排查

#### 1. Cookie 没有发送
**原因**：域名不匹配
**解决**：检查是否遗漏了某个关键域名

#### 2. 显示未登录
**原因**：Cookie 过期或无效
**解决**：重新授权店铺

#### 3. 页面无法加载
**原因**：URL 配置错误
**解决**：检查 webview 的 src 属性

## 💡 技术要点总结

### Cookie 设置最佳实践
1. **识别所有相关域名**：不只是主域名，还包括资源域名、API域名
2. **参考成功案例**：看京东到家的实现，设置了所有相关域名
3. **保持一致性**：webview 和独立窗口的 cookie 设置应该一致

### 美团系平台特点
- 共享 `meituan.com` 主域名
- 需要设置 `e.waimai.meituan.com`（通用登录验证）
- 需要设置 `waimai.meituan.com`（资源域名）

### 饿了么系平台特点
- 共享 `.ele.me` 主域名
- 使用 `setCookies2` 方法（特殊的 cookie 格式）
- 需要设置 domain 为 `.ele.me`
