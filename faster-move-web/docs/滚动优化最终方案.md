# 表格滚动位置恢复 - 最终优化方案

## 🎯 目标
实现标签页切换时的**完全无感**滚动位置恢复。

## ✨ 最终方案

### 核心策略：**临时隐藏 + 快速淡入**

```
切换标签页 → 隐藏表格 → 恢复位置 → 快速淡入 → 完成
   0ms         0ms        30-50ms      20-50ms     完成
```

## 🔧 技术实现

### 1. 响应式状态控制
```typescript
const isRestoringUI = ref(false) // UI 显示状态

// 开始恢复：立即隐藏
isRestoringUI.value = true

// 恢复完成：20ms 后显示 + 30ms 淡入
setTimeout(() => {
  isRestoringUI.value = false
}, 20)
```

### 2. CSS 动画优化
```scss
// 恢复期间：立即隐藏（0ms）
&.is-restoring-scroll {
  :deep(.el-table__body-wrapper) {
    opacity: 0;
    transition: opacity 0ms;
  }
}

// 恢复完成：快速淡入（30ms）
&:not(.is-restoring-scroll) {
  :deep(.el-table__body-wrapper) {
    opacity: 1;
    transition: opacity 30ms ease-out;
  }
}
```

### 3. 双重触发机制
```typescript
// 触发 A：标签页切换
watch(activeTab, () => {
  tryRestoreScrollPosition(15, 50) // 50ms 初始延迟
})

// 触发 B：表格挂载
watch([tableRef, activeTab], () => {
  setTimeout(() => {
    tryRestoreScrollPosition(10, 30) // 30ms 初始延迟
  }, 30)
})
```

### 4. requestAnimationFrame 优化
```typescript
requestAnimationFrame(() => {
  scrollContainer.scrollTop = targetScrollTop
})
```

## ⏱️ 完整时间线

```
0ms    │ 用户点击返回首页
0ms    │ 表格开始渲染（opacity: 0，用户看不到）
30ms   │ 开始恢复滚动位置
50ms   │ 滚动位置恢复完成
70ms   │ 开始显示表格（opacity: 0 → 1）
100ms  │ 淡入完成，完全显示
```

**总耗时**：**100ms**


- 表格挂载时也触发
- 谁先准备好谁先执行
