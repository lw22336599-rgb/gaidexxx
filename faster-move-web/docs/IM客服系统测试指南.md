# IM 客服系统测试指南

## 前置准备

### 1. 配置接口地址

SignalR 连接地址自动使用登录页配置的"默认接口地址"，无需单独配置环境变量。

**配置方式**：
1. 在登录页点击"自定义接口"按钮
2. 输入"默认接口地址"（例如：`http://localhost:5200`）
3. 点击确定保存

SignalR 会自动连接到：
- IM Hub：`{默认接口地址}/im`
- Notification Hub：`{默认接口地址}/notification`

### 2. 确认后端服务

确保以下后端服务已启动：
- ✅ SignalR IM Hub 服务（`/im`）
- ✅ Admin API 服务（用户管理和角色设置）
- ✅ IM Session API 服务（会话管理）

### 3. 准备测试账号

需要至少两个测试账号：
- **管理员账号**：用于设置客服角色和管理客服
- **客服账号**：用于测试客服功能（可以由管理员创建并设置角色）

## 测试场景

### 场景一：客服管理功能测试

#### 1.1 访问客服管理页面

1. 使用管理员账号登录系统
2. 进入菜单：**团队管理 > 客服管理**
3. 应该能看到客服管理页面，显示当前所有客服列表

**预期结果**：
- ✅ 页面正常加载
- ✅ 显示客服列表表格
- ✅ 显示"添加客服"按钮

#### 1.2 添加客服

1. 点击"添加客服"按钮
2. 在弹出的对话框中搜索用户（输入用户名或手机号）
3. 选择一个或多个用户
4. 点击"确定"按钮

**预期结果**：
- ✅ 能够搜索并选择用户
- ✅ 提示"添加客服成功"
- ✅ 客服列表自动刷新，显示新添加的客服
- ✅ 被设置为客服的用户角色包含 `KEFU`

#### 1.3 移除客服

1. 在客服列表中找到一个客服
2. 点击"移除客服"按钮
3. 在确认对话框中点击"确定移除"

**预期结果**：
- ✅ 显示确认对话框
- ✅ 提示"移除客服成功"
- ✅ 客服列表自动刷新，该用户从列表中移除
- ✅ 该用户的 `KEFU` 角色被移除

#### 1.4 搜索和分页

1. 在搜索框输入账号或手机号
2. 选择不同的账号状态（全部/启用/停用）
3. 测试分页功能

**预期结果**：
- ✅ 搜索功能正常工作
- ✅ 状态筛选正常工作
- ✅ 分页切换正常

- ✅ 浮球显示为圆形按钮，带聊天图标

1. 点击客服浮球
2. 观察页面跳转

**预期结果**：
- ✅ 跳转到客服聊天页面（`/customer-service/chat`）

#### 3.1 自动连接测试

- ✅ 连接状态变为"未连接"
- ✅ 浮球上的未读数停止更新

## 常见问题排查

### 问题1：浮球不显示

**可能原因**：
1. 用户没有 `KEFU` 角色
2. 组件未正确导入

**排查步骤**：
1. 打开浏览器控制台
2. 输入：`JSON.parse(localStorage.getItem('userInfo')).admin.role`
3. 检查返回的数组中是否包含 `'KEFU'`

### 问题2：SignalR 连接失败

**可能原因**：
1. 后端服务未启动
2. SignalR 地址配置错误
3. CORS 配置问题

**排查步骤**：
1. 检查登录页是否配置了"默认接口地址"
2. 访问后端服务地址，确认服务正常
3. 验证 SignalR Hub 路径（`{默认接口地址}/im`）是否可访问
4. 查看浏览器控制台的详细错误信息

### 问题3：提示音不播放

**可能原因**：
1. 提示音文件不存在
2. 浏览器自动播放限制
3. IM 设置中关闭了提示音

**排查步骤**：
1. 确认 `public/static/sounds/message-alert.mp3` 文件存在
2. 在有用户交互后再测试（浏览器限制自动播放音频）
3. 检查 IM 设置 store 中的 `alertSoundEnabled` 值

### 问题4：客服管理页面空白或加载失败

**可能原因**：
1. API 接口调用失败
2. 权限不足

**排查步骤**：
1. 打开浏览器网络面板（F12 > Network）
2. 刷新页面，查看 API 请求是否成功
3. 确认当前用户有 `ADMIN` 角色（客服管理需要管理员权限）
