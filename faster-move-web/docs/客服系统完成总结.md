## 🐛 当前控制台错误分析

### SignalR 连接失败
```
Error: Not Found: Status code '404'
Either this is not a SignalR endpoint or there is a proxy blocking the connection.
```

**原因**：后端 SignalR IM Hub 服务未启动或路径配置不正确

**解决方案**：
1. 确认后端 SignalR 服务已启动
2. 确认 SignalR Hub 路径为 `/im` 和 `/notification`
3. SignalR 会自动使用登录页配置的"默认接口地址"
4. 如需修改接口地址，在登录页点击"自定义接口"进行配置

### 其他错误
- `electron.onAddShopRequest 不可用` - 正常，浏览器环境下不影响
- `ECharts DEPRECATED` - 图表库版本警告，不影响功能
