# 手机像 APP 一样打开 H5（局域网固定入口）

仓库已把 **局域网联调参数** 收敛在 **`uniapp_web/.env.development`**。日常联调只要保持该文件与当前办公网一致，**无需在手机或浏览器里再配代理**（H5 已直连 `VITE_DEV_API_BASE` 指向本机 bridge）。

## 1. 当前固化值（与 `.env.development` / bridge 对齐）

| 用途 | 变量 / 说明 | 示例值 |
|------|-------------|--------|
| 电脑在局域网中的 IP | `VITE_LAN_ENTRY_HOST`、`API_BRIDGE_BIND` | `10.10.10.177` |
| H5 开发服务端口 | `VITE_DEV_PORT` | `5173` |
| API 桥接端口 | `API_BRIDGE_PORT` | `3000` |
| 前端请求基址 | `VITE_DEV_API_BASE` | `http://10.10.10.177:3000` |

**首页直达地址（推荐收藏 / 添加快捷方式）：**

```text
http://10.10.10.177:5173/#/pages/index/index
```

**电脑端需常驻两个进程（顺序不限）：**

1. `pnpm run dev:api-bridge`（或 `node scripts/api-dev-bridge.mjs`）— 监听 `10.10.10.177:3000`  
2. `pnpm run dev:h5` — 监听 `10.10.10.177:5173`

手机与电脑需在同一 WiFi（或能访问该 IP 段）。若路由器 DHCP 换了 IP，只改 `.env.development` 里上述主机名为新 IP，再重启 bridge 与 `dev:h5` 即可，**手机快捷方式里的链接同步改成新 IP**。

---

## 2. iOS（Safari）添加到主屏幕

1. Safari 打开上面的首页链接。  
2. 完成一次登录（Token 会留在 Safari 站点数据里，后续一般无需重复登录）。  
3. 点底栏 **分享** → **添加到主屏幕** → 输入名称（如「首页」）→ **添加**。  
4. 以后从桌面图标进入，全屏体验接近原生 App。  

系统更新或清除 Safari 网站数据后，可能需要重新登录。

---

## 3. Android（Chrome / 系统浏览器）

1. 用 Chrome 打开同一首页链接并完成登录。  
2. 右上角菜单 **⋮** → **添加到主屏幕**（或 **安装应用** / **添加至主屏幕**，因机型而异）。  
3. 确认添加；桌面上会出现图标，点入即可。  

若提示「无法安装」，检查是否用了 **http** 非标端口（部分机型需在站点设置里允许桌面快捷方式）。

---

## 4. 开发说明（无需每次手动调试）

- **不要**在手机单独设置 HTTP 代理指向电脑，除非你在故意抓包；当前工程已 `VITE_DEV_API_BASE` 直连 bridge。  
- 首页支持下拉刷新（`pages.json` 已开启 `enablePullDownRefresh`），列表模块支持上拉加载更多。  
- 若仅 IP 变更：改 `.env.development` → 重启 `dev:api-bridge` 与 `dev:h5` → 更新桌面快捷方式的 URL。

---

## 5. 安全检查（可选）

局域网 HTTP 仅建议在可信内网使用。生产环境请使用 HTTPS + 正式域名，并勿将内网地址暴露到公网。
